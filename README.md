# yi-zhang-marketing.github.io
Personal website

## 页面结构

- `index.html`：页面布局、导航、Education & Experience、Posts & Notes，以及全局样式。
- `sections/about-me.js`：About Me 个人信息、简介和联系方式。
- `sections/research.js`：Research 论文和项目内容。

内容模块通过普通 `<script>` 引入，因此无需构建工具，GitHub Pages 和直接打开 `index.html` 都可以使用。更新个人信息或研究成果时，优先编辑对应的 `sections/` 文件。
